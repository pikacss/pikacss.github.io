API 參考 ​

PikaCSS 由數個套件組成，每個套件都有專注的 API。

套件總覽 ​

核心套件 ​

套件用途
@pikacss/core引擎基礎：createEngine、defineEngineConfig、defineEnginePlugin、型別
@pikacss/configCanonical project configuration：defineConfig、scan/report/config 型別
@pikacss/integration建置系統橋接：project generation、prepare/init、原始碼轉換與 generated-state publication
@pikacss/unplugin-pikacssRollup / Webpack 家族 adapters：Vite、Rollup、Rolldown、Webpack、Rspack
@pikacss/nuxt-pikacssNuxt 模組：零設定的 Nuxt 整合

官方外掛 ​

套件用途
@pikacss/plugin-resetCSS reset 注入
@pikacss/plugin-icons透過 Iconify 的圖示 shortcut
@pikacss/plugin-fonts網頁字型載入
@pikacss/plugin-typography長文排版樣式
@pikacss/plugin-design-tokensW3C design token 轉 CSS 變數

工具 ​

套件用途
@pikacss/eslint-config用於靜態分析的 ESLint 規則
