API Reference ​

PikaCSS is composed of several packages, each with a focused API.

Package Overview ​

Core Packages ​

PackagePurpose
@pikacss/coreEngine foundation — createEngine, defineEngineConfig, defineEnginePlugin, types
@pikacss/configCanonical project configuration — defineConfig, scan/report/config types
@pikacss/integrationBuild-system bridge — project runtime, source transformation, generated state
@pikacss/unplugin-pikacssBundler adapters — Vite, Rollup, Rolldown, Webpack, Rspack
@pikacss/nuxt-pikacssNuxt module — zero-config Nuxt integration

Official Plugins ​

PackagePurpose
@pikacss/plugin-resetCSS reset injection
@pikacss/plugin-iconsIcon shortcuts via Iconify
@pikacss/plugin-fontsWeb font loading
@pikacss/plugin-typographyProse typography styles
@pikacss/plugin-design-tokensW3C design tokens to CSS variables

Tooling ​

PackagePurpose
@pikacss/eslint-configESLint rules for static analysis
